# Code of conduct

Be direct, be useful and be kind about it. Disagreeing about code, rules and design is normal here.
Personal attacks, harassment and discrimination are not, and will get you removed from the project's
issues, pull requests and discussions.

## A note for a security project

Examples in issues and pull requests should be small and made up. Don't post real customer code,
secrets, internal hostnames, or working attacks against systems you are not allowed to test. Vulnerability
reports about this project go through a private advisory (see [SECURITY.md](SECURITY.md)), not a public issue.

## Reporting

Email **nexaforge.services@gmail.com**. Reports are kept private.
